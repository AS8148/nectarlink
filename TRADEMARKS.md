# Trademark policy

The NectarLink source code is open source, but the **NectarLink name and
logo** are not covered by the software licenses. This policy exists so that
people can trust that something called "NectarLink" really comes from this
project.

## You're welcome to

- Use the name "NectarLink" to refer to the project, for example in articles,
  reviews, tutorials and videos.
- Say that your software is "compatible with NectarLink" or "based on
  NectarLink", as long as that's accurate.
- Redistribute unmodified official builds under the NectarLink name.

## Please don't

- Distribute a **modified** version under the NectarLink name or logo. Forks
  are welcome, but they need their own name and logo.
- Use the name or logo in a way that suggests the project endorses you, your
  product or your service when it doesn't.
- Use the name or a confusingly similar one in app store listings, domain names
  or social media accounts for software that isn't the official NectarLink.

## Questions

If you're unsure whether your use is fine, open an issue and ask.
